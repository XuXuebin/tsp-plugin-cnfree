# tsp-plugin-cnfree — 免费兜底行情源（新浪分钟 K + 腾讯五档盘口）

> TickStock Panel **外部数据源插件** · 一键安装 · 零 API Key

给 TickFlow 免费档补齐 **分钟 K / 全量分钟 / 五档盘口** 三项能力，全部走公开 HTTP 接口，
**不需要任何 API Key**，也不依赖 SDK。

| 数据集 | 上游接口 | 频率 / 深度 | 单位（宿主内部契约） |
| --- | --- | --- | --- |
| `minute` | 新浪 `CN_MarketDataService.getKLineData` | 1/5/15/30/60 分钟；约 **5 个交易日**（`datalen=1023`） | volume **手**（上游为股，÷100）；amount **元**；datetime **北京墙钟 naive** |
| `full_minute` | 同上 | 当日 1 分钟，逐标的修复轮 | 同上 |
| `depth5` | 腾讯 `qt.gtimg.cn/q=` | 买卖五档，单请求可批量数十只 | 档位数量 **手**；timestamp 毫秒 Unix |

## 为什么需要它

TickFlow 免费档没有 `minute` / `depth5` / `full_minute` 权限：分时图空白、连板梯队判不出
「真封板 / 假涨停」、封单监控拿不到量。这个插件用公开网页行情接口补上这三项，**装上即用**。

## 安装

1. 打开 **设置 → 导入与备份**
2. 拖入本仓库 Release 页的 `tsp-plugin-cnfree-v1.1.1.zip`
   （ZIP 根目录直接包含 `plugin.yaml`，无需解压）
3. 预览确认后点「安装」→ 「查看已安装扩展」
4. 在数据源详情里 **勾选需要接管的能力**（分钟 K / 全量分钟 / 五档盘口）

> 安装不会自动切换路由，需要你手动勾选；不勾的能力会继续走原来的数据源。

## 口径自证（2026-11-19 / 2026-11-20 实测）

- 新浪 1 分钟 `volume` 单位是**股**：1 分钟 `15300` × `1435.25` 元 = `21951879` 元 = 上游 `amount` ✓
- 腾讯买一量 `4` = 4 手 = 400 股（A股最小 100 股，若为「股」则不成立）✓
- 分钟成交额合计与日 K 成交额同量级，无 1000 倍 / 100 倍错位 ✓
- **v1.1.1 修复**：腾讯对「封死涨停」的票返回**卖五档整体为空**（价格 `0.00`、量 `0`）。
  宿主正是靠 `ask_volumes[0] == 0` 判定「涨停真封」，早期版本把空档过滤掉会让真封板
  退化成「待确认」——现在**空档被保留**（量记 0），连板梯队的真假封板判定恢复正常 ✓

## 已知边界

- 分钟历史只有约 **5 个交易日**（免费源浅历史）；**分钟回测**建议用
  [tsp-plugin-xqshare](https://github.com/XuXuebin/tsp-plugin-xqshare)（xtquant，约 1.1 年）
  或 TickFlow Pro / 通达信 `tdxquant`。
- 上游无批量分钟端点：全市场一轮 = 千级请求，属于「修复轮」语义，不适合高频轮询。
- 盘口为快照值，**轮询间隔建议 ≥ 30 秒**。
- 指数分钟 K 走宿主独立的 `/api/index/minute` 实时读取路径，本插件不提供。

## 兼容性

- 宿主 `>= 0.3.37`，Python `>= 3.11`
- 依赖宿主自带：`httpx>=0.27`、`polars>=1.44,<1.45`（无需额外安装）

数据仅供个人研究，**不保证与交易所行情完全一致**，请勿用于实盘下单或资金决策。
